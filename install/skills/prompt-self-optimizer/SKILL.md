# Prompt Self Optimizer（画像查看与解释）

> 重要：prompt 的**消息级自动改写**与**画像自动学习**已由客户端插件 `dsh-prompt-self-client` 全自动完成 —— 每次交互结束后自动分析并更新画像，每次收到新请求时自动按画像改写并注入「优化后的请求」。本 skill 不再负责触发或执行优化/学习。

## 职责

1. **查看画像**：用户要求查看画像（如「看看我的画像」）时，读取本 skill 目录下的 `profile.md` 并清晰展示。
2. **解释画像**：用户询问画像中某条习惯/规则的由来时，结合「学习记录」章节解释。
3. **修改画像**：仅在用户明确要求时编辑 profile.md，并保持「习惯清单 / 防幻觉规则 / 学习记录」三节结构。
4. **`-fin` 确认**：用户输入 `-fin` 表示对最近一次回答满意 —— 插件已自动完成学习，只需简短确认（如「已记录」），**不要**重复分析或写入画像。

## 边界

- 不得主动修改 profile.md（插件自动维护，避免写入冲突）。
- 不得自行「优化」用户 prompt（插件已注入优化版本，以优化版为准执行即可）。
- 用户明确表达的要求始终优先于画像中的任何习惯。
